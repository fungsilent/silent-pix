## Text field

單行文字輸入：label 在上、28px control，含 placeholder、focus、停用、前置圖示與 hint。

<Rules component="text-field">

<ul class="ds-rules">
<Rule component="text-field" id="label">Label 在 control 上方：`text-xs leading-none text-fg-muted`，與 control 間距 `gap-1.5`（6px）。這個間距要明顯小於欄位與欄位之間的距離（兩欄格子 8px、上下排列 12px），label 才看得出屬於哪個 control。不顯示 label 的位置（工具列搜尋）仍保留 label 文字，只是隱藏，靠 placeholder 與圖示說明用途。</Rule>
<Rule component="text-field" id="control">Control 一律 `h-7`、`rounded-md`、`px-3 text-xs`、`bg-field` 加 `border-field-border`；placeholder 用 `text-fg-muted`。所有欄位（text、number、select、editable）與欄位 loading 骨架共用這個高度，也跟 L0 Button 同高，改高度要一起改。</Rule>
<Rule component="text-field" id="focus-disabled">Focus：`border-accent ring-2 ring-accent/40`。停用：`bg-disabled border-line-subtle text-fg-muted`、游標 default，不用 opacity。</Rule>
<Rule component="text-field" id="leading-icon">前置圖示 14px 放在 `left-3`，文字內縮到 `pl-9`。</Rule>
<Rule component="text-field" id="error">錯誤時 control 左邊框換成 `border-l-2 border-l-danger`（只有左邊、不加整圈紅框）；錯誤中取得 focus 時不出現 accent，邊框維持左紅邊、focus ring 改成 `ring-danger/30`，同一個欄位只用一種顏色，欄位下方（`gap-1`）放 L0 field-hint danger；一般說明用 field-hint muted。欄位下方原本有說明時，錯誤取代說明，不另加一行。</Rule>
<Rule component="text-field" id="width">欄位寬度跟隨容器；在 detail panel 中是內容寬 318px。</Rule>
</ul>

</Rules>

## Field hint

欄位下方或 footer 內的一行說明或錯誤。

<Gallery min="300px">
<State component="field-hint" state="muted" label="muted · default" frame="w-max flex rounded-lg border border-line-subtle bg-surface p-4" />
<State component="field-hint" state="danger" label="danger" frame="w-max flex rounded-lg border border-line-subtle bg-surface p-4" />
</Gallery>

<Rules component="field-hint">

<ul class="ds-rules">
<Rule component="field-hint" id="tones">只有 muted 與 danger 兩種 tone，`text-xs`。muted 單行 `truncate`、不加 icon；danger 前面加 12px 警告三角（與 Issue chip 同一個圖示），文字 `leading-4` 可換行不截斷，三角對齊第一行。</Rule>
<Rule component="field-hint" id="field-error">欄位錯誤在欄位下方放 danger hint，輸入框只加左側紅邊（見 Text field 的 error 規則）；沒有輸入框的置中引導區（例如整個視窗可拖放的開啟頁）只放 hint；拖放區的錯誤留在框內（見 File drop）。Dialog 的操作失敗與讀檔失敗這類要說明原因的錯誤不用 hint，用 Callout。</Rule>
</ul>

</Rules>
