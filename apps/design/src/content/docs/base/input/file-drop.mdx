<Rules component="file-drop">

<ul class="ds-rules">
<Rule component="file-drop" id="drop-area">單一檔案的拖放區，同時接受拖放與點擊選檔：`border-dashed border-line rounded-md`、`py-6` 置中三行——20px ImagePlus、`text-xs text-fg-secondary` 的操作說明、`text-[11px]` 的可接受格式。</Rule>
<Rule component="file-drop" id="hover-drag">Hover `bg-hover`；拖曳檔案經過時框與底轉 accent：`border-accent bg-accent/10`，告訴使用者放開就會收下；圖示與文字不轉色。</Rule>
<Rule component="file-drop" id="invalid">格式或大小不符時錯誤留在拖放區內：整塊與 dragging 同結構、換成 danger：`border-danger bg-danger/10`，圖示維持 muted、不轉紅（狀態一律由框與底表達，圖示在任何狀態都不轉色），操作說明維持 fg-secondary，可接受格式那一行換成 11px 警告三角加原因，高度不變、不推動下方內容。放入可接受的檔案、清除選擇或再次拖曳進來（dragging 樣式優先）即恢復。只在放下後檢查，拖曳途中不預判格式；可接受的檔案會直接取代先前的選擇，所以同一個檔案可以重選。</Rule>
<Rule component="file-drop" id="replace">已經有檔案時說明改成「Drop or choose another image」，拖放區仍在，作為替換入口。停用時整塊 `opacity-50`、游標 default。</Rule>
<Rule component="file-drop" id="empty-placeholder">虛線框也是「這裡還沒有東西」的視覺語言：唯讀檢視沒有檔案時用同樣的虛線框（不可點、底色 active）顯示 empty 文字，不要用實線框。</Rule>
</ul>

</Rules>
