<Rules component="number-field">

<ul class="ds-rules">
<Rule component="number-field" id="same-as-text">外觀與 text-field 相同（`h-7`、label 在上、同一組 focus／停用），差在數字輸入；瀏覽器的上下箭頭隱藏，只靠鍵入與鍵盤上下鍵調整。</Rule>
<Rule component="number-field" id="pairs">成對的數值（Steps／CFG、Width／Height）用兩欄 `grid-cols-2 gap-2` 併排，不各佔一列。</Rule>
<Rule component="number-field" id="error">錯誤同 text-field：不合法的那一格加左側紅邊；成對時 danger hint 放在兩欄下方、跨兩欄（`col-span-2`），由紅邊指出是哪一格。</Rule>
<Rule component="number-field" id="compact">Compact 只用在 slider 旁：`w-16 h-6 px-2 text-center`，label 隱藏（由 slider 那列的 label 說明）。</Rule>
</ul>

</Rules>

## Slider

連續數值的拖曳控制，永遠與 compact number-field 併排。

</Gallery>

<Rules component="slider">

<ul class="ds-rules">
<Rule component="slider" id="track">Track `h-2 rounded-full bg-track`，已填範圍與 thumb 都是 `bg-accent`；thumb `size-4` 圓形，focus 時 `ring-2 ring-accent/40`。整個控制區高 `h-5`。</Rule>
<Rule component="slider" id="with-number">Slider 永遠與 compact number-field 併排（`gap-2.5`），數字可直接鍵入精確值；label 只在上方出現一次。</Rule>
<Rule component="slider" id="disabled">停用時整個 slider 降為 `opacity-60`（不是 field 的停用底色），旁邊的 number 走 field 停用樣式。</Rule>
<Rule component="slider" id="error">拖曳不會產生錯誤；只有旁邊鍵入的數字可能不合法，此時紅邊加在 compact number 上，danger hint 放在整列下方。Track 不變色。</Rule>
</ul>

</Rules>
