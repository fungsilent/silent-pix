## Image viewer

全螢幕看圖：backdrop 蓋住疊加層區域（Desktop 標題列以下，見 App），可縮放、平移、左右切換。Generate、task browser、compare、參考圖共用。

<Rules component="image-viewer">

<ul class="ds-rules">
<Rule component="image-viewer" id="overlay">蓋住疊加層區域的 overlay（範圍見 App 的疊加層區域），底色 `bg-backdrop backdrop-blur-[6px]` 並淡入；底固定是暗的，不用 stage 色。點 backdrop 或 Esc 關閉；拖曳平移後放開不算點擊關閉。板上以 `absolute` 畫在固定高度的框內。</Rule>
<Rule component="image-viewer" id="close">右上只有 close（size-8 glass、icon 16），不放其他動作。</Rule>
<Rule component="image-viewer" id="counter">左上：2 張以上時顯示 `n / total` glass chip。</Rule>
<Rule component="image-viewer" id="paging-strip">左右切換 `size-8` glass、icon 18，2 張以上才出現。縮圖列只在 2 張以上且 Fit 時出現，放大後收起；選取縮圖 `ring-2 ring-on-stage`（viewer 底固定暗，不用 `ring-stage-fg`）。</Rule>
<Rule component="image-viewer" id="pan-minimap">放大到超出可視範圍時游標變 grab 可平移，右下出現 minimap（長邊 96px、`bg-stage-overlay-muted`），框出可見範圍，可點擊或拖曳跳轉。</Rule>
<Rule component="image-viewer" id="load-error">圖片載入失敗時隱藏該圖，置中放 L0 StatusMessage regular 的圖片無法顯示（image-off 圖示＋「Image unavailable」、不放按鈕），不出 minimap。viewer 底固定是暗的，圖示方塊改用 glass（`border-stage-line bg-stage-control`），圖示與文字用 `text-stage-overlay-text`，兩種主題都讀得到；同樣維持中性。</Rule>
<Rule component="image-viewer" id="zoom-controls">左下是 zoom-controls。</Rule>
</ul>

</Rules>

## Zoom controls

疊在可縮放圖片左下的 glass 縮放條。image-viewer 與 compare-workspace 共用。

<Rules component="zoom-controls">

<ul class="ds-rules">
<Rule component="zoom-controls" id="bar">glass 條 `h-8 gap-1 px-1`，固定在所在 stage 左下 `bottom-6 left-6`：−、目前倍率、+、分隔線、`1:1`。按鈕 `size-7 rounded`、icon 15，hover `bg-stage-control-hover`。</Rule>
<Rule component="zoom-controls" id="percent">倍率欄固定 `w-[54px] tabular-nums`，Fit 時顯示「Fit」，否則顯示百分比。</Rule>
<Rule component="zoom-controls" id="limits">Fit 時 − 不可用、到 800% 時 + 不可用，皆照 L0 Stage button 停用。</Rule>
<Rule component="zoom-controls" id="editing">點倍率切成輸入框（`bg-stage-control-hover`，只輸入數字），Enter 或失焦套用、Esc 取消。</Rule>
<Rule component="zoom-controls" id="one-to-one">`1:1` 在 Fit 與 100% 之間切換；雙擊圖片同效。100% 指一個圖片像素對一個螢幕實體像素，依系統顯示縮放換算（例如 Windows 150% 縮放下，圖片顯示為 CSS 尺寸的 2/3），所有倍率都以此為準。</Rule>
</ul>

</Rules>
