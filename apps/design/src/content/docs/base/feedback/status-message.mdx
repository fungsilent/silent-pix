<Rules component="status-message" part="regular">

<ul class="ds-rules">
<Rule component="status-message" id="structure">結構固定：icon 方塊（只限 regular、可省）→ 文字區 `flex flex-col gap-1`（標題可省、說明可省，但至少一行）→ 按鈕（可省）。所有空／錯誤狀態都用這一個元件，不在使用處另組一份。</Rule>
<Rule component="status-message" id="regular">regular 用在工作區、格狀瀏覽、比較 stage、metadata 等大區塊：`max-w-[280px] gap-3`，由所在區塊負責置中（stage 底色用 `bg-stage-empty`）；標題 `text-sm font-medium`，說明 `text-xs leading-relaxed`，icon 方塊 `size-12 rounded-xl`、icon 21／stroke 1.5，按鈕用 L0 Button default 加 `mt-1`、icon 14。</Rule>
<Rule component="status-message" id="types">外觀中性：圖示方塊（`border-line-subtle bg-elevated text-fg-muted`）與文字都不轉色；唯一的紅色是讀取失敗訊息前的警告三角（同 Field hint：顏色交給圖示，不交給文字）。用法依內容區分：**沒有內容**是標題＋說明，有條件但沒結果時不放按鈕；**尚未選取或加入**另加一顆 solid accent 引導鈕（guide，與 Bar 上同一個動作）；**讀取失敗**（重試可能會好）只寫一句 muted 訊息＋中性 soft Retry，不用標題、不放圖示方塊，訊息前加 `text-danger-fg` 警告三角（regular 12px、compact 11px，對齊第一行），文案寫明是讀取失敗（例如「Failed to load …」），與空狀態區分；**圖片無法顯示**（重試也不會好）是 image-off 圖示＋一句 muted「Image unavailable」，不放按鈕。compact 不放圖示方塊。</Rule>
<Rule component="status-message" id="copy-by-cause">文案依原因區分：完全沒資料、單一 filter（各自一組標題與說明）、多 filter 無結果、搜尋無結果。說明要告訴使用者下一步。</Rule>
<Rule component="status-message" id="not-included">不屬於本元件：載入中用 Skeleton；未選取時仍維持欄位外觀的編輯器佔位；浮在圖片上的短暫訊息。</Rule>
</ul>

</Rules>

<Rules component="status-message" part="compact">

<ul class="ds-rules">
<Rule component="status-message" id="compact">compact 用在側欄 panel 與 dialog 內的清單：`gap-2 px-3 py-8`，放在清單區頂端、水平置中，不垂直置中（與清單第一列同一個位置，空、讀取失敗都一樣）；標題 `text-xs font-medium`，說明 `text-[11px] leading-relaxed`，按鈕用 L0 Button compact、icon 13，不放 icon 方塊。</Rule>
<Rule component="status-message" id="next-page-error">已經有資料時，下一頁載入失敗在清單或格狀尾端附加一個 compact load error（訊息 + Retry），舊資料保留，不換掉整個區塊。</Rule>
</ul>

</Rules>
