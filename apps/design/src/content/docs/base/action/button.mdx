<Rules component="button" part="variant">

<ul class="ds-rules">
<Rule component="button" id="variant-tone">Variant 表示視覺重量，tone 表示語意色：`solid` 是畫面上唯一的主要動作（Generate、Save、Add images、Save and connect），一個區塊最多一顆；`soft` 是一般動作與 dialog 的取消／確認；`ghost` 是低重量的次要動作（Clear、Show all）與工具列文字鈕。</Rule>
<Rule component="button" id="tones">Tone 只有 `accent`／`neutral`／`danger`。破壞性動作（刪除、封存）一律 soft danger，不用 solid danger；solid neutral 與 ghost accent／ghost danger 已定義但目前畫面不使用，新增前先確認 soft 是否足夠。未指定時預設為 soft neutral。</Rule>
<Rule component="button" id="outline">Outline 是 ghost 加上 `border-line`：實線用於獨立的次要動作（Clear、參考圖來源連結），虛線用於「從其他地方挑選」的入口（Search image library），與 L0 file-drop 的虛線框成對出現。</Rule>
<Rule component="button" id="flag-tones">Task flag 的 Pin／Discard 是唯二的額外 tone，只用 soft 重量（`bg-pin/22`、`bg-discard/22`），Unflag 是 ghost neutral；顏色只在 flag 動作上出現，不挪作他用。</Rule>
</ul>

</Rules>

<Rules component="button" part="states">

<ul class="ds-rules">
<Rule component="button" id="focus-border">所有按鈕保留 `border border-transparent`，focus 時才換成 accent 邊框加 `ring-2 ring-accent/40`，尺寸不跳動；danger tone 的 focus 改用 danger 色，neutral 仍用 accent。</Rule>
<Rule component="button" id="disabled">停用：`opacity-60`，顏色不變，游標維持箭頭（桌面慣例，不用 `cursor-not-allowed`）；所有不可操作的按鈕都用這一個樣子，沒有「不可按但外觀不變」的例外。Pending 時按鈕停用並把文字換成進行式（Creating...／Saving...／Deleting...／Testing...），圖示保留；同一組的其他按鈕（例如 dialog 的 Cancel）一併停用。一個進行中的變更會讓所有受它影響的按鈕（不論在哪個區塊）都用同樣的停用樣式，直到完成。</Rule>
</ul>

</Rules>

<Rules component="button" part="layout">

<ul class="ds-rules">
<Rule component="button" id="size">尺寸：所有尺寸都是 28px 高，同一列的控制項因此對齊。default `px-3 py-[5px] text-xs`（單行時 28px，內容多行時可長高）；bar `h-7 px-3 text-xs`，放在 48px 高的 bar 內；compact `h-7 px-2 text-[11px]`，用在工具列與面板內的小動作（Retry、選取操作）；dialog footer `h-7 min-w-20 text-xs`。Bar 內的主要 solid 加 `font-semibold`。</Rule>
<Rule component="button" id="icon">圖示在文字左側、間距 `gap-2`；一般 13px／stroke 1.8，bar 主要鈕 14–16px。會先開確認 dialog 的按鈕不加刪節號，文字直接寫動作（例如 `Delete`）。進行中文案（Saving...、Loading...）以三個半形句點「...」結尾，不用單一字元「…」。這是英文文案的規則；繁體中文照中文排版習慣用「…」。</Rule>
</ul>

</Rules>
