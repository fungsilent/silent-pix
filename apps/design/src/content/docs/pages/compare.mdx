#### 工作區

<ul class="ds-rules">
<Rule component="compare-workspace" id="structure">結構：Bar（`h-12 bg-surface`）→ 目前圖片 stage（`bg-stage`）→ compare-strip。Bar 不放頁名，Header 的模式選單已經寫著 Compare；左側只有 `shown / total`（`text-xs text-fg-secondary`），一眼看出有沒有隱藏的圖。</Rule>
<Rule component="compare-workspace" id="bar-actions">Bar 右側依序是 ghost Eye 圖示鈕（提示「Show all」）、ghost ListX 圖示鈕（提示「Clear comparison list」）與 accent ImagePlus 圖示鈕（提示「Add images」，開 multiple picker）。Clear 只清空比較清單。Show all 在部分圖片隱藏時出現在 Bar，全部隱藏時改由中央引導提供。</Rule>
<Rule component="compare-workspace" id="current-chip">目前圖片左上只放序號：`h-6` 的 accent 實心方塊，對應縮圖列的同一個序號；名稱與尺寸看右側 Detail，不放在圖上，也不放 Bar。左下放 zoom-controls。Compare 不開全螢幕 viewer：工作區本身就是檢視器，要更大的畫面就收合右側 Detail，只有一套縮放狀態。</Rule>
<Rule component="compare-workspace" id="empty-guide">空清單使用與 Metadata 開啟畫面一致的全工作區引導，文字主按鈕為「Add images」。全部隱藏時保留 Bar 與縮圖列，中央使用「All images hidden」與「Show all」引導（Eye 圖示，同 Bar 上的 Show all 鈕）。兩種引導使用 L0 StatusMessage regular。</Rule>
<Rule component="compare-workspace" id="selection">第一次加入圖片時選第一張，後續加入保留目前選取。隱藏或移除目前圖片時選下一張可見圖，沒有下一張就選上一張。恢復可見時保留現有選取，若當時沒有選取就選第一張可見圖。</Rule>
<Rule component="compare-workspace" id="zoom-pan">放大後與 image-viewer 相同：圖片超出可視範圍時游標變 grab 可平移，stage 右下出現 minimap；左下 zoom-controls 顯示倍率。縮圖列不收起。</Rule>
<Rule component="compare-workspace" id="image-error">目前圖片載入失敗時隱藏該圖，置中於 stage 放 L0 StatusMessage regular 的圖片無法顯示（image-off 圖示＋muted「Image unavailable」、不放按鈕，維持中性），不出 minimap；Bar、序號與縮圖列照常。</Rule>
<Rule component="compare-workspace" id="keyboard">←／→ 只在可見項間循環；有 overlay 開著時不攔。</Rule>
</ul>

#### 縮圖列

<ul class="ds-rules">
<Rule component="compare-strip" id="strip">`h-20 bg-stage-strip`、上緣 `border-stage-line-subtle`。縮圖永遠單列，能放下時置中，超出時從首張開始橫向捲動。</Rule>
<Rule component="compare-strip" id="index-badge">主圖與縮圖都用圖片在完整清單中的位置當序號，前面的圖片隱藏時，後面的序號照舊。縮圖不放名稱，只在左上放 18px 的序號角：選中為 accent，其餘 `bg-stage-overlay`。</Rule>
<Rule component="compare-strip" id="selected">選取照 L0 stage 縮圖選取（`ring-2 ring-stage-fg`）。沒選到的縮圖不變淡，因為已隱藏的縮圖已經用了變淡。</Rule>
<Rule component="compare-strip" id="hover-actions">縮圖列刻意壓低、縮圖照圖片比例，所以每張只用兩個角：hover 整張時，序號角換成 eye-off（點擊隱藏），右上出現移除 X（hover 轉 `text-stage-danger`）；兩者都是 18px、icon 11px。已隱藏的縮圖序號角常駐 eye-off（點擊恢復），整張 `opacity-40 grayscale`。default 的第一張為 hover 態。</Rule>
<Rule component="compare-strip" id="unavailable">縮圖載入失敗時疊 `bg-stage-control` 與置中 16px image-off icon，不放文字。</Rule>
</ul>

</Rules>

<ul class="ds-rules">
<Rule component="image-detail" id="same-as-task-detail">寬度、收合與標題列同 task-detail（展開 380px、收合 40px、標題「Detail」），且與 task-detail 共用同一個收合狀態：在兩者之間切換時維持原本的展開或收合；內容間距 `gap-3 px-4 pb-5`，區塊之間用細分隔線。</Rule>
<Rule component="image-detail" id="content">由上而下：ID（mono 11px）與 Created；IMAGE 區 160px 高 `bg-active` 預覽框，圖片等比置中；CONFIG 區 Width｜Height 兩欄，固定停用。</Rule>
</ul>

</Rules>

<Rules component="compare-image-picker">

<ul class="ds-rules">
<Rule component="compare-image-picker" id="purpose">加入比較用，可多選；標題「Add images to compare」。</Rule>
<Rule component="compare-image-picker" id="size">dialog `w-[1600px]`、高度撐滿視窗扣掉邊距；窄時縮到可用寬度（四周留 16px）。Backdrop `bg-backdrop`。</Rule>
<Rule component="compare-image-picker" id="layout">外框是 dialog：頂端 48px 標題列只有標題（14px semibold）與右上關閉鈕；中間左側是 40px 篩選直條（頂端留 48px 與工具列對齊），右側是與 **task-browser** 相同的工具列＋格狀區；底部 48px footer（上方 `border-line-subtle`）只放靠右的 Apply（solid accent，沒有選取時停用）。取消用關閉鈕或 Esc，沒有 Cancel 按鈕；選取資訊在工具列的選取 chip，不放 footer。</Rule>
<Rule component="compare-image-picker" id="filters">篩選直條沿用 task-list 直條的 icon chips：上半 Task flag 多選（All／Unflag／Pin／Discard），隔一條分隔線，下半 Type 單選（All 用圖示；Input／Output 不用圖示，直接用與卡片小標同款的 9px 粗體大寫「IN」「OUT」字樣，兩者一眼可分）；選中 `bg-selected text-fg`。Type 選 Input 時 Task 整組停用（照 L0 停用樣式）並清掉 flag 篩選。</Rule>
<Rule component="compare-image-picker" id="toolbar">工具列與 task-browser 相同：48px 高，左側 234px 搜尋（task name 或 task ID）＋選取 chip，最右縮圖大小滑桿（調欄數，規則同 task-browser，與 task-browser 分開記住）。</Rule>
<Rule component="compare-image-picker" id="grid">格狀與 task-browser 相同：依滑桿的欄數 `repeat(<欄數>, 1fr)` 撐滿寬度、間距 12px、內距 8px，捲動區預留捲軸位置。卡片框與 task-card 相同（`p-2 rounded-lg`、縮圖下 `mt-2` 一列 28px），hover `bg-hover` 並浮出右上 glass 勾選鈕；選中 `border-accent bg-accent/20 ring-2 ring-accent/40`，右上換成 accent 實心的選取序號。</Rule>
<Rule component="compare-image-picker" id="already-compared">已在比較中的圖不可選：不顯示勾選鈕，整張壓 `bg-stage-overlay-muted` 並置中大 Check；此時 discard 不再另外壓暗。</Rule>
<Rule component="compare-image-picker" id="flag-state">Flag 只顯示狀態：左上角摺 26px（pin／discard 色），discard 另壓 `bg-discard-dim`；picker 內沒有 flag 操作。</Rule>
<Rule component="compare-image-picker" id="source-label">卡片下方一列：左側來源（task 名稱 #n 或 input，12px medium；沒有名稱時為 task ID 前 8 碼並用等寬字），右側 `in`（`bg-info/18 text-info-fg`）／`out`（`bg-elevated text-fg-muted`）小標。</Rule>
<Rule component="compare-image-picker" id="loading-empty">首次載入以與卡片同框的骨架卡鋪滿兩列（方形縮圖＋名稱條＋小標條）；下一頁載入照 L0 Skeleton next-page。格狀區屬於大區塊，空狀態與載入失敗用 L0 StatusMessage regular、置中在格狀區：沒有圖是 icon 方塊（Images）＋「No images yet／Generated outputs and uploaded inputs will appear here.」，不放按鈕；讀取失敗是警告三角＋「Failed to load images.」＋ Retry。</Rule>
<Rule component="compare-image-picker" id="next-page">捲到底自動載下一頁；下一頁失敗時在格狀尾端附加 L0 StatusMessage compact 載入失敗（muted「Failed to load more images.」+ Retry，不用紅字），已載入的卡片保留。</Rule>
<Rule component="compare-image-picker" id="selection">有選取時工具列顯示與 task-browser 相同的「n selected ×」chip，× 清空選取；沒有選取時不顯示 chip。</Rule>
<Rule component="compare-image-picker" id="representative">板上卡片只放代表性的一組狀態，實際張數依資料而定。</Rule>
</ul>

</Rules>
