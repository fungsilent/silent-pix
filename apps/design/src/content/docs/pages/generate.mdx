#### Browser

<ul class="ds-rules">
<Rule component="task-browser" id="layout">整塊 `bg-surface`、填滿可用寬高。左側保留 **task-list** 的 40px 直條（篩選與 Grid view 不變；Grid view 用 selected 樣式表示目前是格狀檢視，再按一次回到清單；頂端收合鈕在 browser 模式不放，留白），右側是工具列加格狀區：工具列固定在上方，格狀區獨立捲動（細捲軸）；卡片最小寬度由工具列的縮圖大小滑桿決定（140–320px，預設約 200px），欄數依可用寬度自動排（`repeat(auto-fill, minmax(<size>, 1fr))`），間距 12px、內距 8px。</Rule>
<Rule component="task-browser" id="marquee">在格狀區空白處按下拖曳會畫出框選矩形（`border-accent bg-accent/15`），框到的卡片即時變成 checked；拖曳期間不選取文字。從勾選鈕或 flag 鈕起手不會開始框選。</Rule>
<Rule component="task-browser" id="selection-reset">搜尋或篩選變更時清空勾選；勾選中的 task 因搜尋／篩選離開目前結果時，自動從勾選移除。</Rule>
<Rule component="task-browser" id="empty-error">空狀態與載入失敗用 L0 StatusMessage regular，在格狀區置中：完全沒有 task 是「No tasks yet / Generated tasks will appear here.」；有搜尋文字而無結果是「No matching tasks / Try another search or filter.」；沒有搜尋、只篩一個 flag 時用該 flag 的專屬文案；沒有搜尋、多個 flag 篩選無結果是「No matching tasks / Try a different task filter.」。空狀態不放按鈕。</Rule>
<Rule component="task-browser" id="loading">首次載入以 16 張骨架卡整組替換格子。捲到底載入下一頁時格子尾端出現跨整列的「Loading...」純文字。已有資料時下一頁失敗，在格子尾端附加 regular 載入失敗訊息＋Retry，既有卡片保留；沒有資料時失敗則整個格狀區換成置中的失敗訊息。</Rule>
<Rule component="task-browser" id="overlays">整張卡片只有一種單擊：選取這個 task（右側 Detail 顯示它）；雙擊卡片開啟審片模式（**task-review**）；Ctrl／⌘＋單擊切換勾選，hover 時右上的勾選框照舊可用。刪除確認 dialog 與審片模式疊在本檢視之上，各自見對應元件。</Rule>
</ul>

#### 工具列
