## Setting card

設定頁的卡片：標題＋說明，下方以分隔線切出欄位區或設定列。

<Gallery min="560px">
<State component="setting-card" state="appearance" label="Appearance · language + theme" frame="w-full max-w-[520px]" />
</Gallery>

<Rules component="setting-card" part="card">

<ul class="ds-rules">
<Rule component="setting-card" id="layout">Settings 頁的單位；頁面內容單欄、最寬 520px，卡片間距 `gap-3.5`。卡片 `rounded-lg border border-line-subtle bg-surface`。</Rule>
<Rule component="setting-card" id="appearance">Appearance 卡兩列：Language（Select，選擇存在這台裝置）與 Theme（Segment group：Dark／Light，切換立即生效）。主題只在這裡切換，Header 不放主題鈕。</Rule>
<Rule component="setting-card" id="header">卡頭：標題 13px semibold，可接一個 `bg-elevated` 底的大寫小 tag（目前只有 Connection 帶「Desktop」）；下方一行 11.5px muted 說明。卡頭以下每一區都以 `border-t border-line-subtle px-3.5` 起頭。</Rule>
<Rule component="setting-card" id="blocks">區塊兩種：欄位區（`py-3`，放 L0 Select／Text 等欄位與說明）與設定列（`min-h-14 justify-between`，左側標題＋提示、右側控制項）。</Rule>
<Rule component="setting-card" id="row-control">設定列的控制項是 segment group：`h-7` `bg-elevated` 容器，選中項用 L0 selected 樣式，未選中為 ghost `text-fg-muted`。</Rule>
</ul>

</Rules>

## Connection

Desktop 才有的 Server 連線設定：輸入、測試、儲存。

<State component="setting-card" state="connection-testing" label="Connection · testing" frame="w-full max-w-[520px]" />
<State component="setting-card" state="connection-connected" label="Connection · connected" frame="w-full max-w-[520px]" />
<State component="setting-card" state="connection-failed" label="Connection · check failed" frame="w-full max-w-[520px]" />
<State component="setting-card" state="connection-invalid" label="Connection · invalid URL" frame="w-full max-w-[520px]" />
<State component="setting-card" state="connection-saving" label="Connection · saving" frame="w-full max-w-[520px]" />
</Gallery>

<Rules component="setting-card" part="connection">

<ul class="ds-rules">
<Rule component="setting-card" id="connection-desktop-only">Connection 卡只在 Desktop 平台出現。已有儲存的 URL 時主按鈕是「Save and reload」，否則「Save and connect」；改到不同 Server 時先開確認 dialog。</Rule>
<Rule component="setting-card" id="test-result">測試結果只有 Connected／Connection check failed 兩種，是連線狀態不是錯誤：留在按鈕右側，用 1.5 的圓點加語意 fg 色文字，不用 badge；尚未測試時不顯示，修改輸入即清除。</Rule>
<Rule component="setting-card" id="invalid">URL 不合法時，danger Field hint 取代欄位下方的說明文字，輸入框加左側紅邊（同 Text field 的 error），不另加一行。</Rule>
<Rule component="setting-card" id="read-error">設定讀取失敗時在欄位區上方多一區，用 compact StatusMessage 的 load-error：一句 muted 訊息＋預設 Retry，不用紅色。</Rule>
<Rule component="setting-card" id="button-states">URL 為空、測試中或儲存中兩顆按鈕都用 L0 Button 停用樣式；進行中的那顆依 L0 pending 換成「Testing...」／「Saving...」。</Rule>
</ul>

</Rules>

## Confirm dialog

儲存 Server 位址並重新載入前的確認。

<Gallery min="520px">
<State component="settings-confirm-dialog" state="server-save" label="server · save" frame="relative h-[300px] overflow-hidden rounded-lg border border-line-subtle bg-canvas" />
<State component="settings-confirm-dialog" state="server-saving" label="server · saving" frame="relative h-[300px] overflow-hidden rounded-lg border border-line-subtle bg-canvas" />
</Gallery>

<Rules component="settings-confirm-dialog">

<ul class="ds-rules">
<Rule component="settings-confirm-dialog" id="structure">結構固定：header（`text-base font-bold` 標題 + `text-xs leading-5 text-fg-muted` 說明 + 右上 soft 關閉鈕 `size-7`）、body（受影響的對象，名稱用 `font-mono`）、footer（`border-t`）。</Rule>
<Rule component="settings-confirm-dialog" id="backdrop">Backdrop `bg-backdrop`；dialog 置中，`rounded-lg border-line bg-surface shadow-2xl`。板上以 `absolute` 畫在固定高度的框內。</Rule>
<Rule component="settings-confirm-dialog" id="pending">確認進行中依 L0 Dialog pending：兩顆按鈕都用 L0 Button 停用樣式，確認鈕文案換成「Saving...」；進行中也擋掉關閉，右上關閉鈕一併停用。</Rule>
<Rule component="settings-confirm-dialog" id="server-save">Server 儲存 dialog 寬 `max-w-lg`，確認鈕是 solid accent「Save and reload」（不是破壞性操作），body 顯示完整 URL（`break-all`）；錯誤顯示在 Settings 頁上而不是 dialog 內。</Rule>
</ul>

</Rules>

<Rules component="settings-screen">

<ul class="ds-rules">
<Rule component="settings-screen" id="title-bar">標題列高 48px、`border-b border-line-subtle`；內容區獨立捲動，`px-4 py-[18px]`，卡片間距 `gap-3.5`。</Rule>
<Rule component="settings-screen" id="card-order">卡片順序固定：Appearance、Dev Settings、Connection（僅 Desktop）。</Rule>
<Rule component="settings-screen" id="no-endpoint">Desktop 尚未設定 Server（no endpoint）時一律顯示本頁；Header 的模式選單停用、服務狀態隱藏，Tools 與 Settings 照常；Connection 卡為未設定狀態。</Rule>
<Rule component="settings-screen" id="save-error">儲存設定失敗（例如 Desktop 設定寫不進去）時，錯誤進 Header 的 Issue chip（來源 Connection）；確認 dialog 已關閉，錯誤不放進卡片內。</Rule>
<Rule component="settings-screen" id="server-switch">改到不同 Server 時先開確認 dialog，蓋住整個視窗（含 Header）；儲存後整個 app 重新載入。</Rule>
</ul>

</Rules>
