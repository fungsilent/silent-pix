## Setting section

設定頁的區段：小標題，下面接設定列或欄位區。

<Gallery min="680px">
<State component="setting-section" state="appearance" label="Appearance · language + theme" frame="w-full max-w-[640px] bg-surface px-4 pt-4" />
</Gallery>

<Rules component="setting-section" part="section">

<ul class="ds-rules">
<Rule component="setting-section" id="layout">Settings 頁的單位，版面照抄 Detail layout：不用卡片框，直接放在 `bg-surface` 上；區段 `flex flex-col gap-3`，區段之間只插一條 Line（`my-1 border-t border-line-subtle`），沒有可接的下一個區段時不畫線。內容單欄、最寬 640px，外層 `gap-3`。</Rule>
<Rule component="setting-section" id="appearance">Appearance 區兩列：Language（Select，寬 200px，選擇存在這台裝置）與 Theme（Segment group：Dark／Light，切換立即生效）。主題只在這裡切換，Header 不放主題鈕。</Rule>
<Rule component="setting-section" id="header">區段只有標題、沒有說明，照抄 Detail 的 section 標題：`text-[11px] font-semibold uppercase tracking-[0.08em] text-fg-title`，外包 `py-1`；不加平台 tag（Connection 只在 Desktop 出現，不需要再標示）。需要說明的內容寫在個別設定列的提示裡。</Rule>
<Rule component="setting-section" id="blocks">區塊兩種：設定列（`justify-between`，左側 label＋提示、右側控制項，控制項維持自身寬度靠右）是預設；欄位區（欄位撐滿整欄）只給需要寬度的輸入，例如 Connection 的 URL。label 照抄 Detail row 的 `text-xs leading-none text-fg-muted`，提示 `text-[11px] leading-4 text-fg-muted`。區段內不畫分隔線，列與列只以 `gap-3` 分開。唯一和 Detail 不同的是列不用 74px 固定標籤欄：設定項多半帶提示，標籤欄放不下，所以 label 在左、控制項靠右。</Rule>
<Rule component="setting-section" id="row-control">設定列的控制項是 segment group（`h-7` `bg-elevated` 容器，選中項用 L0 selected 樣式，未選中為 ghost `text-fg-muted`）或固定寬度的 Select；同一區段的控制項右緣對齊。</Rule>
</ul>

</Rules>

<Rules component="setting-section" part="connection">

<ul class="ds-rules">
<Rule component="setting-section" id="connection-desktop-only">Connection 區只在 Desktop 平台出現。已有儲存的 URL 時主按鈕是「Save and reload」，否則「Save and connect」；改到不同 Server 時先開確認 dialog。</Rule>
<Rule component="setting-section" id="test-result">測試結果只有 Connected／Connection check failed 兩種，是連線狀態不是錯誤：留在按鈕右側，用 1.5 的圓點加語意 fg 色文字，不用 badge；尚未測試時不顯示，修改輸入即清除。</Rule>
<Rule component="setting-section" id="invalid">URL 不合法時，danger Field hint 取代欄位下方的說明文字，輸入框加左側紅邊（同 Text field 的 error），不另加一行。</Rule>
<Rule component="setting-section" id="read-error">設定讀取失敗時在欄位區上方多一區，用 compact StatusMessage 的 load-error：一句 muted 訊息（前加警告三角）＋預設 Retry，文字不轉紅。</Rule>
<Rule component="setting-section" id="button-states">URL 為空、測試中或儲存中兩顆按鈕都用 L0 Button 停用樣式；進行中的那顆依 L0 pending 換成「Testing...」／「Saving...」。</Rule>
</ul>

</Rules>

## Confirm dialog

儲存 Server 位址並重新載入前的確認。

<Gallery min="520px">
<State component="settings-confirm-dialog" state="server-save" label="server · save" frame="relative h-[300px] overflow-hidden rounded-lg border border-line-subtle bg-canvas" />
<State component="settings-confirm-dialog" state="server-saving" label="server · saving" frame="relative h-[300px] overflow-hidden rounded-lg border border-line-subtle bg-canvas" />
</Gallery>

<Rules component="settings-confirm-dialog">

<ul class="ds-rules">
<Rule component="settings-confirm-dialog" id="structure">結構固定：header（`text-base font-bold` 標題 + `text-xs leading-5 text-fg-muted` 說明 + 右上 soft 關閉鈕 `size-7`）、body（受影響的對象，名稱用 `font-mono`）、footer（`border-t`）。</Rule>
<Rule component="settings-confirm-dialog" id="backdrop">Backdrop `bg-backdrop`；dialog 置中，`rounded-lg border-line bg-surface shadow-2xl`。板上以 `absolute` 畫在固定高度的框內。</Rule>
<Rule component="settings-confirm-dialog" id="pending">確認進行中依 L0 Dialog pending：兩顆按鈕都用 L0 Button 停用樣式，確認鈕文案換成「Saving...」；進行中也擋掉關閉，右上關閉鈕一併停用。</Rule>
<Rule component="settings-confirm-dialog" id="server-save">Server 儲存 dialog 寬 `max-w-lg`，確認鈕是 solid accent「Save and reload」（不是破壞性操作），body 顯示完整 URL（`break-all`）；錯誤顯示在 Settings 頁上而不是 dialog 內。</Rule>
</ul>

</Rules>

<Rules component="settings-screen">

<ul class="ds-rules">
<Rule component="settings-screen" id="title">不用頁面 Bar：本頁沒有操作，標題屬於內容。標題是內容欄的第一個元素（`text-base font-semibold`，與區段左緣對齊），隨內容一起捲動、不固定；位置由 Header 的 Settings 鈕選中狀態表示。內容區 `bg-surface`、獨立捲動，`px-4 pt-6 pb-5`；標題到第一個區段 20px。</Rule>
<Rule component="settings-screen" id="section-order">區段順序固定：Appearance、Connection（僅 Desktop）、Dev Settings；Dev Settings 是開發用，始終放在最下面。</Rule>
<Rule component="settings-screen" id="no-endpoint">Desktop 尚未設定 Server（no endpoint）時一律顯示本頁；Header 的模式選單停用、服務狀態隱藏，Tools 與 Settings 照常；Connection 區為未設定狀態。</Rule>
<Rule component="settings-screen" id="save-error">儲存設定失敗（例如 Desktop 設定寫不進去）時，錯誤進 Header 的 Issue chip（來源 Connection）；確認 dialog 已關閉，錯誤不放進區段內。</Rule>
<Rule component="settings-screen" id="server-switch">改到不同 Server 時先開確認 dialog，蓋住疊加層區域（Desktop 標題列以下，見 App）；儲存後整個 app 重新載入。</Rule>
</ul>

</Rules>
