## App model

Silent Pix 是桌面 App，瀏覽器版用的也是同一套介面。所有畫面一律照桌面 App 的習慣設計，不照網頁。這是最上層的規則，其他規則都在它底下；唯一的例外是觸控與手機寬度（最後兩條）。

<Rules component="token-app-model">

<ul class="ds-rules">
<Rule component="token-app-model" id="workspace-window">視窗就是工作區：Header 固定在頂端，下方各區塊填滿視窗高度、各自捲動。整頁不捲動，不做網頁式的長頁面（手機版面例外，見 mobile）。</Rule>
<Rule component="token-app-model" id="bar-and-panels">用 Bar 與面板分割空間：側欄固定寬度，主區吃掉剩餘寬度。不把內容置中成一欄、不設頁面最大寬度；只有表單類內容（Settings）可以限制欄寬，讓欄位不會拉得過長。</Rule>
<Rule component="token-app-model" id="no-web-header">沒有網頁式的頁首：不放 hero、大標題或整段介紹文字。頁面或區塊名稱寫在 Bar 標題；需要說明時，寫在用得到它的空狀態或欄位提示裡。</Rule>
<Rule component="token-app-model" id="controls-not-links">操作用控制項，不用網頁慣例：不用文字連結、底線分頁或麵包屑。切換用 Segment group，換頁用 Header 的模式分頁與選單。</Rule>
<Rule component="token-app-model" id="arrow-cursor">游標照桌面習慣：按鈕、選項、清單列、選單項目這些控制項維持箭頭，不顯示網頁連結的手指游標（不用 `cursor-pointer`）。文字輸入顯示 I 形游標，可拖曳的元件顯示 grab，停用照 L0 停用樣式。可不可以點，由外觀和 hover 底色表達，不靠游標。</Rule>
<Rule component="token-app-model" id="in-place">操作就地完成：不換頁、不重新整理。結果留在原處呈現（按鈕狀態、StatusMessage），錯誤進 Header 的 Issue chip，進行中用停用樣式與進行式文案表示。</Rule>
<Rule component="token-app-model" id="error-layers">錯誤與問題只集中在一個地方：**Header 的 Issue chip**，整個 App 只有這一個，面板 Bar 不放 chip。進 Header 的有兩種：**操作失敗**（按下按鈕後失敗，例如改名、flag、儲存設定）與**前置檢查**（目前不能執行某個動作的原因，例如沒有 workflow、選項載入失敗、mapping 失效）；每則標出來源（面板或欄位名）。原處只做標記、不放第二份清單：相關欄位用 Badge（例如 missing）或停用表示，主要按鈕停用。以下留在原處、不進 Header：**欄位錯誤**（輸入值不合法）用 danger Field hint 取代該欄說明；**dialog 內的操作失敗**放 footer 上方的 Callout 錯誤條，dialog 保持開啟；**讀檔失敗**這類要說明原因、又不屬於欄位的錯誤用 Callout；**整塊內容出不來**（載入失敗、檔案讀不到、App 啟動失敗）用 StatusMessage 取代那塊內容。不用會自己消失的 toast，錯誤不插入內容中間把版面擠開。**顏色**：說明文字一律不轉紅，紅色只出現在警告三角等圖示、狀態點、有底色的容器（Callout、Badge、狀態 chip）與欄位左紅邊；StatusMessage 維持中性，只有讀取失敗在訊息前加警告三角；「圖片無法顯示」不是錯誤，不加。danger 按鈕的紅色表示破壞性動作，不在此限。各元件的外觀與狀態見 [Field hint](/base/input/text-field/#field-hint/rules)、[File drop](/base/input/file-drop/)、[Callout](/base/feedback/callout/)、[StatusMessage](/base/feedback/status-message/) 與 Task failure 的規則。</Rule>
<Rule component="token-app-model" id="open-files">檔案用桌面習慣開啟：開檔按鈕，或把檔案拖進視窗；拖曳經過時，整個接收區顯示接收框。</Rule>
<Rule component="token-app-model" id="desktop-first">設計新元件或新頁面時，先想桌面 App 會怎麼做；和網頁慣例衝突時，以桌面 App 為準。</Rule>
<Rule component="token-app-model" id="touch">觸控裝置（沒有 hover 能力，與視窗寬度無關）不能依賴 hover、Ctrl／⌘＋單擊或拖曳框選：只在 hover 時出現的控制項改為常駐，多選改用長按進入勾選模式。其餘桌面規則照舊。</Rule>
<Rule component="token-app-model" id="mobile">視窗寬度 &lt; 640px 時，有手機版面的頁面改用手機版面（目前只有 [Generate · Mobile](/pages/generate-mobile/)）：一次顯示一個全螢幕畫面、主要操作固定在底部列。需要長內容的畫面由瀏覽器整頁捲動：Header 黏在頂端、底部列黏在底部，捲動時手機瀏覽器可以收起網址列；不在頁內另做捲動區，也不觸發下拉重新整理。沒有手機版面的頁面維持桌面版面，視窗不夠寬時水平捲動。</Rule>
</ul>

</Rules>

## Color

Chrome 一律純 neutral，不帶色溫——這是影像工具，chrome 的色溫會干擾對圖片顏色的判斷。顏色只用來表達語意：accent、flag、status。 色塊底下是該 theme 的實際值；alpha 色塊疊在 `surface` 上。

<Rules component="token-color">

#### Surface

<ul class="ds-rules">
<Rule component="token-color" id="panel-border">相鄰 panel 之間用 `border-r border-line` 分隔（見示意右側），不留縫。</Rule>
<Rule component="token-color" id="hover-alpha">`hover` 是 alpha，疊在任何底上都會相對加深；但底本來就是 `elevated` 的元件要用 `elevated-hover`，因為 bg 是替換不是疊加。</Rule>
<Rule component="token-color" id="field-not-active">輸入框用 `field`，不要拿 `active` 代替——兩個角色在 Light 的方向相反。</Rule>
</ul>

#### Line & Text

<ul class="ds-rules">
<Rule component="token-color" id="fg-steps">降低文字層次只換 `fg-*` 階，不用 `opacity`。唯一例外是 disabled 控制項。</Rule>
<Rule component="token-color" id="spacing-not-lines">需要比 `line-subtle` 更淡的分隔時，改用間距而不是再造一階線。</Rule>
</ul>

#### Accent & Status

<ul class="ds-rules">
<Rule component="token-color" id="on-solid">實心底上的字與 icon 用 `text-on-stage`（白），不用 `text-fg`。</Rule>
<Rule component="token-color" id="soft-tint">染色底用 `bg-*-soft` token，比例會隨 theme 變；不要寫死 `/15`。Button 的 `/15` 是既有例外。</Rule>
<Rule component="token-color" id="primary-action">主要動作（Generate、Save、Apply）用 accent solid，一個區塊只放一個；破壞性動作（含確認 dialog 的刪除鈕）用 `tone="danger"` 的預設 soft。</Rule>
</ul>

#### Flag

<ul class="ds-rules">
<Rule component="token-color" id="flag-state-action">縮圖左上的角摺是「狀態」，常駐不可點；行右端的按鈕是「操作」，只在 hover 時出現。Inactive 一律中性 ghost，顏色只在 active 出現。</Rule>
<Rule component="token-color" id="flag-ink">Gold / mist 是淺色，實心底上的 icon 必須用 `*-ink`，不用白。Discard 另加 `discard-dim` 壓暗照片。</Rule>
</ul>

#### Stage

<ul class="ds-rules">
<Rule component="token-color" id="glass-recipe">疊在圖片上的控制項一律用 glass recipe：`border-stage-line bg-stage-control text-on-stage hover:bg-stage-control-hover backdrop-blur-[8px]`。</Rule>
<Rule component="token-color" id="viewer-backdrop">全螢幕 viewer 的底走 `backdrop`，不用 `stage`。</Rule>
</ul>

</Rules>

## Typography

Manrope Variable 搭配 Noto Sans TC Variable。介面是高密度工具，預設內容字級是 `text-xs`（12px）；更大的字只給標題與空狀態，更小的只給 meta 與 overline。

<Rules component="token-typography">

<ul class="ds-rules">
<Rule component="token-typography" id="font-weight">字重只用 `font-medium`（強調值、按鈕）與 `font-semibold`（標題）；`font-bold` 只給 Dialog title。</Rule>
<Rule component="token-typography" id="leading">單行標題、label 用 `leading-none` 配合固定高度容器對齊；多行內容用 `leading-relaxed`。</Rule>
<Rule component="token-typography" id="numbers-truncate">數字欄位加 `tabular-nums`；可能過長的單行加 `truncate` 並確保父層 `min-w-0`。</Rule>
</ul>

</Rules>

## Interaction state

所有互動元件共用同一組狀態表現。下方為靜態攤開的結果，實際 class 帶 `hover:`／`focus-visible:`／`disabled:` 前綴。

<Gallery min="100%">
<State component="token-state" state="matrix" label="狀態矩陣" themes="both" frame="flex flex-col gap-6 p-5" />
</Gallery>

<Rules component="token-state">

<ul class="ds-rules">
<Rule component="token-state" id="focus">Focus 一律 `focus-visible:border-accent focus-visible:ring-2 focus-visible:ring-accent/40`；danger 元件換成 danger 色。元件預留 `border border-transparent`，focus 時才不會跳動。</Rule>
<Rule component="token-state" id="selected">選取態用 `bg-selected text-fg`：和 hover 一樣是 alpha 疊加層，但深一階，疊在 surface、elevated 或清單列上都看得出來，滑過其他項目時也分得出哪個是選中的。不畫框線，也不要另用 accent 底表示選取。</Rule>
<Rule component="token-state" id="stage-selected">Stage 上的縮圖（縮圖列、viewer）不用選取底色，改用 `ring-2` 加所在底色的前景色：跟著 theme 變色的 stage 用 `ring-stage-fg`，永遠是暗底的全螢幕 viewer 用 `ring-on-stage`。不用 accent。</Rule>
<Rule component="token-state" id="disabled">停用的輸入框用 `theme.field.disabled`；停用的按鈕、導覽項目與選項一律 `disabled:opacity-60`，游標維持箭頭，不用 `cursor-not-allowed`；唯一例外是疊在照片上的 stage 玻璃鈕，規則見 L0 Stage button。</Rule>
<Rule component="token-state" id="field-error">欄位錯誤不改輸入框外觀，改在欄位下方顯示 `FieldHint tone="danger"`。</Rule>
</ul>

</Rules>

## Motion

動畫只用在「出現」：140ms ease-out。消失不做動畫。`prefers-reduced-motion` 下全部關閉。
